# ÉLAN — сайт салона красоты с онлайн-записью

Демо-проект для портфолио: публичный сайт салона и рабочая система записи с админ-панелью.
Чистый HTML / CSS / JavaScript, без сборки и зависимостей — открывается с любого статического хостинга
(Vercel, Netlify, GitHub Pages) или просто двойным кликом по `index.html`.

**Страницы**

| Адрес | Что это |
| --- | --- |
| `index.html` | Сайт: услуги, мастера, работы, отзывы, контакты + виджет записи и «Мои записи» |
| `admin.html` | Админ-панель (демо-PIN `1234`): расписание дня, неделя, журнал, клиенты, блокировки |

## Что умеет система записи

**Для клиента**
- Запись в 4 шага: услуга → мастер (или «любой») → дата и время → контакты.
- В календаре подсвечены только дни, где реально есть свободные окна; в списке времени — только слоты,
  куда помещается услуга целиком с учётом графика мастера, других записей и перерывов.
- Подтверждение с номером записи; раздел «Мои записи» по номеру телефона с историей и отменой.
- Живой показатель «ближайшее свободное окно» на главной.

**Для администратора**
- Расписание дня по мастерам (таймлайн), KPI: записей, план выручки, загрузка, ожидают подтверждения.
- Недельная матрица загрузки мастер × день.
- Журнал всех записей: поиск по имени / телефону / номеру, фильтры, смена статуса в один клик, экспорт CSV.
- Карточка записи: статусы (новая, подтверждена, завершена, отменена), готовое напоминание в WhatsApp, удаление.
- База клиентов: визиты, сумма, последний визит, любимая услуга.
- Блокировки: перерывы, обучение, выходные для мастера (с предупреждением, если в интервале уже есть записи).
- Создание записи вручную (например, по телефонному звонку).
- Защита от двойной брони — коллизии проверяются при каждом сохранении.

## Структура

```
index.html        сайт
admin.html        админ-панель
css/styles.css    дизайн-токены и все компоненты (сайт + админка)
js/data.js        НАСТРОЙКИ САЛОНА: контакты, прайс, мастера, графики
js/store.js       хранилище записей + движок расчёта свободных слотов
js/site.js        логика сайта и мастера записи
js/admin.js       логика админ-панели
img/              фотографии (демо)
```

## Как настроить под свой салон

1. `js/data.js` → объект `SALON`: название, город, адрес, телефон, часы, PIN админки, шаг сетки, горизонт записи.
2. Там же `SERVICES` (категория, название, цена, длительность в минутах) и `MASTERS`
   (имя, роль, фото, какие категории делает, график по дням недели: `1: [10, 20]` — понедельник с 10 до 20, `0: null` — воскресенье выходной).
3. Замените фото в `img/` и тексты отзывов в `REVIEWS`.
4. Цвета и шрифты — переменные в начале `css/styles.css`.

## Как подключить настоящий сервер

В демо записи хранятся в `localStorage` браузера, поэтому клиент и админ видят одни данные только на одном устройстве.
Для боевого режима заменяются методы в `js/store.js` (`all`, `create`, `update`, `remove`, `blocks`, `addBlock`, `removeBlock`)
на запросы к вашему API — интерфейс уже выделен, остальной код менять не нужно. Подойдёт любой бэкенд:
Supabase / Firebase (без своего сервера), Node + SQLite, Google Sheets через Apps Script.
Туда же логично вынести SMS/WhatsApp-напоминания и настоящую авторизацию администратора.
